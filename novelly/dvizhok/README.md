# Движок сайта для коротких новелл

PHP 8 без базы данных, под обычный хостинг с Apache.

- Новеллы лежат в `content/novelly/` файлами .docx или .txt, порядок по номеру в имени
- Админка `/admin`: загрузка .docx, порядок, скрытие, своё превью, отзывы, настройки
- Цели Яндекс Метрики на дочитывание (25, 50, 75 %, до конца), переходы в Telegram
- Превью для Telegram и соцсетей генерируется для каждой новеллы
- Анонимная форма отзыва: в Telegram-бот и/или на почту, копия в CSV
- Настройки в `config.php` или в админке

Локальный запуск: `php -S 127.0.0.1:8090 router-dev.php`. Экраны: `ekrany-telefon.png`, `prevyu-telegram.png`.
