# Детали для 3D-печати

Пять параметрических моделей: кронштейн полки, заглушка в профильную трубу 25×25, шестерня, корпус под плату ESP32 с крышкой, клипса на трубу 20 мм. Размеры и допуски задаются в `model/parts.py` (CadQuery), на выходе STEP для CAD и STL для слайсера.

```
pip install cadquery
python model/parts.py
```
