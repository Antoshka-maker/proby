# Фигурка пары по фотографиям

Скульптура высотой 20 см для печати на SLA-принтере, сделанная по набору фотографий.

- Поза, пропорции и одежда повторяют фото: парадная форма с аксельбантом, погонами и шевроном, ремень с бляхой, платье с пышными рукавами, сумка, коса.
- Одна целая (watertight) модель на круглой подставке, 93 × 83 × 200 мм, около 3,5 млн треугольников, STL.
- Несколько кругов правок по замечаниям: посадка головы, положение руки, шеврон.
