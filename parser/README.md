# Парсер каталога в Excel

Обходит каталог учебного магазина books.toscrape.com (1 000 товаров, 50 страниц), собирает название, категорию, цену, рейтинг, наличие и ссылку, сохраняет в `katalog-knig.xlsx` со сводкой по категориям. Повторы запросов при сбоях, лог в консоль.

```
pip install requests beautifulsoup4 openpyxl
python parser.py
```
