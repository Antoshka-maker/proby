# Отчёт из сырой выгрузки

`make.py` берёт выгрузку чеков сети кофеен (демо-данные, 29 тысяч чеков за три месяца) и собирает `otchet-kofeyni.xlsx`: сводки по точкам и месяцам, рост, топ товаров, графики. Все итоги считаются формулами Excel, поэтому отчёт пересчитывается при замене данных.

```
pip install openpyxl
python make.py
```
