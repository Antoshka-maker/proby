# Сверка эквайринга, СБП и чеков ОФД

Сопоставляет оплаты из выписок банка (эквайринг и СБП) с чеками ОФД по сумме и времени и выгружает реестр расхождений в Excel: оплаты без чека, чеки без оплаты, возвраты.

- `gen_demo.py` создаёт демо-выгрузки `demo_*.csv` (данные выдуманные)
- `sverka.py` делает сверку и пишет `reestr-proba.xlsx`
- `proverka.py` сверяет результат с заранее известными расхождениями

```
pip install pandas openpyxl
python gen_demo.py && python sverka.py
```
