# Кабинет заказов на Vue 3

Небольшая админ-панель для приёма заказов: вход, сводка, список с поиском, фильтром, сортировкой и страницами, карточка заказа с редактированием, создание и удаление.

Демо-вход: логин `demo`, пароль `demo`. Сервера нет: запросы `fetch('/api/...')` уходят в фейковый REST-бэкенд прямо в браузере (`src/api/mockServer.ts`), данные хранятся в localStorage. Чтобы подключить настоящий API, достаточно убрать `installMockFetch()` из `main.ts`, компоненты и сторы не меняются.

## Стек

Vue 3 (Composition API, `<script setup>`), TypeScript, Pinia, Vue Router, Vite, Vitest и Vue Test Utils. Без UI-библиотек, вёрстка своя, адаптив под телефон (таблица превращается в карточки), тёмная тема по системной настройке.

## Что внутри

```
src/
  api/          http.ts — обёртка над fetch (токен, JSON, понятные ошибки)
                orders.ts — методы REST API
                mockServer.ts, seed.ts — фейковый бэкенд и демо-данные
  stores/       auth.ts — сессия; orders.ts — список, фильтры, загрузка
  views/        Login, Dashboard, Orders, Order
  components/   OrdersTable, OrderForm, AppPagination, StatusBadge
  composables/  useDebounced
  utils/        validation.ts, format.ts
tests/          28 тестов: API, стор, компоненты, утилиты
```

Несколько решений, на которые стоит посмотреть:

- Фильтры и страница живут в адресе (`#/orders?status=done&page=2`), список можно сохранить в закладки или переслать.
- Поиск с задержкой 300 мс, а стор отбрасывает устаревшие ответы: если пользователь быстро печатает и ответы приходят не по порядку, на экране остаётся результат последнего запроса.
- Любой фильтр сбрасывает на первую страницу; если удалить последний заказ на последней странице, список сам перейдёт на предыдущую.
- Форма проверяет поля на клиенте и показывает ошибки валидации сервера (422); при уходе с несохранёнными изменениями спрашивает подтверждение.
- Hash-роутинг и `base: './'`, чтобы сборка работала на любом статическом хостинге.

## Запуск

```bash
npm install
npm run dev        # разработка
npm test           # тесты
npm run build      # проверка типов и сборка в demo/
```
