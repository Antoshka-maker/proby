# Telegram-бот для приёма заявок

Бот на aiogram 3. Показывает меню, отвечает на частые вопросы, собирает заявку за три шага (имя, телефон, описание задачи), просит подтвердить и пересылает её администратору. Все заявки сохраняются в базу SQLite `requests.db`.

## Запуск

1. Создайте бота у @BotFather и скопируйте токен.
2. Скопируйте `.env.example` в `.env` и впишите токен.
3. Установите зависимости и запустите:

```
pip install -r requirements.txt
python bot.py
```

4. Напишите боту `/id` из того чата, куда должны приходить заявки, впишите число в `ADMIN_CHAT_ID` и перезапустите бота.

Тексты меню, вопросов и контактов лежат в начале файла `bot.py`.
