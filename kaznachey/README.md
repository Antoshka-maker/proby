# Бот-казначей родительского чата

Бот для мессенджера MAX: ведёт сборы класса (кто сдал, сколько осталось), напоминает должникам, принимает расходы с фото чеков и показывает отчёт. Данные в SQLite.

- `kaznachey.py`: логика (сборы, взносы, расходы, отчёты)
- `max_bot.py`: подключение к Bot API MAX, запуск: `MAX_TOKEN=... python3 max_bot.py kaznachey.sqlite`
- `proverka.py`: прогон сценария без сети, пример диалога в `dialog.json`
- `kak-rabotaet.png`: как выглядит работа бота
