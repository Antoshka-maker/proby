# Портфолио

Витрина: https://antoshka-maker.github.io/proby/

## Сайты и интерфейсы

- [Главная страница стоматологии с 3D-зубом](stomatologiya/): Живая 3D-модель зуба на первом экране и сцены при прокрутке: имплант, подбор оттенка, врачи, отзывы, запись. Адаптив под телефон.
- [Кабинет заказов на Vue 3](vue-kabinet/): Вход, сводка, таблица заказов с поиском, фильтром, сортировкой и страницами, карточка заказа с редактированием. Бэкенд эмулируется в браузере, покрыто тестами.
- [Лендинг загородного отеля «Хвоя»](otel-les/): Летняя и новогодняя версии одним переключателем. Фото на первом экране объёмно двигается за мышью по карте глубины. Форма подбора дат и гостей.
- [Сайт для коротких новелл](novelly/): Удобное чтение с телефона, оглавление, опрос после прочтения. Движок на PHP без базы данных: админка, загрузка .docx, цели дочитывания в Метрике, превью для Telegram, анонимные отзывы.
- [Сайт мастера на час для Германии](master-na-chas/): Одностраничник на немецком и русском: услуги с ценами, заявка по телефону или в мессенджер, Impressum и Datenschutz.
- [Лендинг производителя блочного льда](blochnyy-led/): Калькулятор заказа прямо на первом экране: вид льда, количество, доставка, итоговая цена и заявка.
- [Сборщик заказа электрики](elektrika/): Менеджер вводит количество, программа сама подбирает артикулы по упаковкам с наименьшей ценой. Номенклатура лежит отдельным файлом и правится без кода.
- [Пошаговая 3D-сборка детали](3d-prosmotr/): Гибка планки примыкания из листа по шагам: пуск, пауза, шаг вперёд и назад, вращение мышью или пальцем.

## Данные и автоматизация

- [Дашборд молочного производства](dashbord/): Загружаете Excel прямо в браузере и сразу видите надои, выручку, цену литра, жирность и поголовье по дням. Без сервера и установки.
- [Сверка эквайринга, СБП и чеков ОФД](sverka/): Скрипт сопоставляет оплаты банка с чеками кассы по сумме и времени, находит пропущенные чеки и возвраты и выгружает реестр расхождений в Excel.
- [Отчёт из сырой выгрузки](excel-otchet/): 29 тысяч чеков за три месяца превращаются в отчёт по точкам и месяцам: рост, топ товаров, график по дням. Всё на формулах, отчёт пересчитывается сам.
- [Парсер каталога в Excel](parser/): Собирает 1 000 товаров с учебного магазина за 33 секунды: название, категория, цена, рейтинг, наличие. Сводка по категориям на формулах.
- [Структура интернет-магазина по семантике](struktura/): Каркас категорий магазина стройматериалов: уровни, URL, H1, тип страницы и запросы кластера.
- [CSV → KiCad → Gerber](kicad/): Скрипт строит дорожки и отверстия печатной платы по таблице координат и выгружает Gerber и сверловку. Проверено в KiCad 7.

## Боты

- [Telegram-бот для приёма заявок](bot-zayavki/): Меню, частые вопросы, заявка в три шага с проверкой телефона, уведомление администратору, база заявок.
- [Магазин в Telegram](bot-magazin/): Сценарий бота для продаж: каталог с фото, корзина, расчёт доставки, оплата и трек-номер без участия продавца.
- [Бот-казначей родительского чата](kaznachey/): Ведёт сборы класса: кто сдал, сколько осталось, напоминания и отчёт о расходах с чеками.

## Игры

- [Три мини-игры для кофейни](igry/): Колесо подарков, ловилка десертов и «найди пары». Работают на телефоне, рекорд сохраняется, без библиотек.
- [«Хадата»: атмосферный текстовый квест](hadata/): Ночь на метеостанции: текст, звук и смена сцен, выбор влияет на концовку.

## Графика и печать

- [Гиф-баннер 240×400 для клиники](banner-kliniki/): Анимированный баннер для Яндекс Директа по брендбуку клиники, 39 КБ при лимите 120. Прошёл модерацию с первого раза.
- [Акционный баннер для слайдера](bannery/): Яркий баннер 1920×600 для главной интернет-магазина: товары, скидка, кнопка.
- [Рекламный макет в газету](gazeta/): Модуль 25×11 см в PDF для типографии: CMYK, фото 300 dpi, сумма красок под газетную бумагу, отдельная ч/б версия.
- [Макет сувенирного магнита 70×50](magnit/): Векторный макет для типографии по эскизу: всё в кривых, CMYK, фигурный контур вырубки отдельным слоем, фон навылет 2,5 мм, плавный край под заливку смолой.
- [Векторизация под гравировку и резку](vektor/): Трафарет с мостиками, логотип под гравировку, подставка по эскизу, кронштейн с размерами, наклейка для плоттера.

## 3D

- [Фигурка пары по фотографиям](figurka/): Скульптура 20 см для печати на SLA: поза и одежда как на фото, парадная форма с аксельбантом и шевроном, складки платья, коса. Одна целая модель на подставке.
- [Детали для 3D-печати](3d-detali/): Кронштейн, заглушка в профильную трубу, шестерня, корпус под плату ESP32, клипса на трубу. Параметрические модели с допусками под печать.
- [Топперы на торт: лыжи и сноуборд](toppery/): Модели под печать на 31×22 мм: снег, доска, крепления разными цветами, плоское дно.
- [3D-модель генераторной установки по фото](gazogenerator/): Упрощённая сборка из девяти узлов: рама, шкаф, двигатель, фильтр, радиатор, АКБ. Формат STEP.
- [Рельеф и горизонтали по точкам съёмки](relef/): Триангуляция точек, горизонтали в DXF для CAD и объёмный рендер участка.
- [Концепт выставочного стенда](stend/): Быстрый эскиз стенда с брендированием, стойкой и мебелью, два ракурса.

## Тексты и видео

- [Тексты: сайт, объявление, статья](teksty/): Главная страница мастерской обуви, редактура объявления «было/стало», статья про домашний Wi-Fi.
- [Субтитры к видео на три языка](subtitry/): Расшифровка с таймкодами, перевод на английский и турецкий по смыслу, файлы .srt и вшитые субтитры.
